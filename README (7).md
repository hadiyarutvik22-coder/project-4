# 📊 List Operations Project (1D & 2D)

A menu-driven Python program for working with **1D lists** and **2D
lists**. It lets the user enter sample data or manual data, then choose
operations from a menu.

## ✨ Features

-   **1D and 2D Lists** --- choose a one-dimensional or two-dimensional
    list.
-   **Sample or Manual Data** --- use built-in sample values or enter
    your own values.
-   **Display** --- print the current dataset.
-   **Statistics** --- show length, sum, minimum, maximum, and average.
-   **Average** --- calculate the average of the values.
-   **Duplicates** --- find repeated values.
-   **Args and Kwargs** --- demonstrate `*args` and `**kwargs`.
-   **Factorial** --- calculate a factorial using recursion.
-   **Fibonacci** --- display Fibonacci terms using recursion.
-   **Lambda Filtering** --- filter values above a threshold and double
    the filtered values.
-   **Global Summary** --- update a global summary dictionary.
-   **Multiple Values** --- return minimum, maximum, and average
    together.
-   **Sorting** --- sort list data in ascending or descending order.
-   **Change Data / Exit** --- enter a new dataset or close the program.

## 🧰 Requirements

-   Python 3
-   No external Python packages are required.

## ▶️ How to Run

1.  Download or clone this project.

2.  Open a terminal in the project folder.

3.  Run:

    ``` bash
    python "project 4.py"
    ```

4.  Select `1` for a 1D list or `2` for a 2D list.

5.  Select sample data or manual data.

6.  Choose an operation from the menu.
